# Alkebuleum Web (Vite + React + TypeScript + Tailwind + MUI)

## Quickstart
```bash
npm install
npm run dev
```
Then open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```

## Stack
- React 18 + TypeScript
- Vite + @vitejs/plugin-react-swc
- Tailwind CSS
- MUI (Material UI) v6
