— What is Alkebuleum

A sovereign ledger, built where it's used.

Alkebuleum is a public, permissioned Layer 1 designed around the realities of African governance, commerce, and identity. Most blockchains were built for somewhere else. This one is built for here — and for the global family that's part of it.

— For developers

Familiar tools.
Sovereign rails.

Alkebuleum is EVM-compatible. Bring your Solidity contracts, your JavaScript SDKs, your team's existing skills — and deploy onto infrastructure actually built for where you ship.

  • Native SDKs in TypeScript, Python, Go, and Rust
  • EVM compatibility — deploy Solidity with no rewrites
  • Predictable fees denominated in USD, paid in $ALKEB
  • Free testnet, faucet, and developer grants
Read the docs View on GitHub
deploy.ts 
// connect to the Alkebuleum L1
import { AlkebClient } from "@alkebuleum/sdk";

const client = new AlkebClient({
  network: "mainnet",
  region:  "africa-west-1",
});

// issue a verifiable citizen credential
await client.identity.issue({
  subject:  "did:alkeb:0xA4…f12c",
  schema:   "national-id/v2",
  issuer:   "gov.lr",
  validity: "10y",
});

// settle a cross-border payment
await client.payments.send({
  from:   "alkeb:diaspora/us",
  to:     "alkeb:wallet/0x9d…12",
  amount: "250.00 USD",
});
