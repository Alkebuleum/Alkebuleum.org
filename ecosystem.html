Identity Layer

AIChain

Where identity meets the immutable ledger.

AIChain is the reputation and identity infrastructure layer of the Alkebuleum ecosystem. On-chain credentials for humans and AI agents — verifiable, portable, and composable across every application in the network.

  • On-chain identity credentials and verifiable attestations
  • AI and human reputation scoring that compounds across interactions
  • Portable identity — one profile, the entire ecosystem
  • Sybil-resistant access control for dApps
  • Crosschain identity bridge for broader Web3 use

Decentralized Exchange

JollofSwap

Born in West Africa. Built for global liquidity.

Named after the beloved West African dish — a convergence of ingredients into something greater. JollofSwap is the native DEX of Alkebuleum, Uniswap V2-powered with deep ALKE pairs and identity-gated pool access.

  • Automated market maker (AMM) built on Uniswap V2 mechanics
  • ALKE/USDC and ALKE/MAH primary liquidity pairs
  • Liquidity mining and farming incentives
  • Identity-gated premium pools via AIChain integration
  • One-click swaps for the full ecosystem token suite

Wallet SDK

AmVault

The developer's key to the ecosystem.

AmVault is the official React-based wallet auth and transaction SDK for Alkebuleum. EIP-1193 compatible with batch transactions, message signing, and seamless dApp integration. Published on npm.

  • React component library — drop in AmVault Connect in minutes
  • EIP-1193 provider compatibility for ecosystem-wide integration
  • Batch transaction bundling for gas efficiency
  • Message signing and on-chain authentication flows
  • Published on npm as amvault-connect@0.1.9

AI Intelligence Layer

Nuru AI

Light, in Swahili. Intelligence, for the ecosystem.

Nuru — meaning "light" in Swahili — is the AI guide of the Alkebuleum ecosystem. A full web application helping users navigate the chain, understand assets, and interact intelligently with every protocol. Wallet-gated via AmVault, powered by Anthropic.

  • Natural language interface for all Alkebuleum protocols
  • Wallet-gated intelligence — authenticate with AmVault to unlock
  • On-chain data analysis and portfolio interpretation
  • Modular React component architecture, backend on Railway
  • Anthropic Claude API integration for on-chain context

Token Economy

How ALKE Powers Everything

01

Gas on Alkebuleum

Every smart contract call and transfer across all four applications requires ALKE as gas. Demand is structural.

02

JollofSwap Liquidity

ALKE is the base pair on JollofSwap. Every ecosystem token pairs with ALKE, driving continuous demand as the DEX grows.

03

Identity Staking

AIChain reputation requires ALKE staking to establish and maintain. Higher reputation = more ALKE locked.

04

AI Services

Nuru AI's advanced intelligence features require ALKE as payment for on-chain analysis and portfolio intelligence.

05

SDK Transactions

Every dApp built on AmVault runs on Alkebuleum and pays gas in ALKE. Developer adoption multiplies ecosystem demand.

06

Governance

ALKE holders govern protocol parameters, treasury deployment, and future ecosystem additions through on-chain voting.
